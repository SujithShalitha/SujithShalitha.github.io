Keyboard shortcuts

Anywhere in Windows

KeysWhat they do
Ctrl + Alt + C (changeable)Quick Convert: the wheel for the selected files, or for the clipboard image when nothing is selected
Your Presets key (optional)the wheel, straight on its Presets page
Your Repeat last key (optional)redo the last choice for that kind of file, no wheel

Set them in Settings → Quick Convert shortcut and More shortcuts. Function keys work too: F6–F9 on their own, or any function key with Ctrl, Alt or Shift. Windows and other apps already use F1–F5 and F10–F12.
