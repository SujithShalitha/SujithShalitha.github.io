S Converter documentation

S Converter is a free, all-in-one file converter for Windows 10 and 11. It converts images, video, audio, documents, PDFs and archives on your own PC: nothing is uploaded, there is no account, and it works without an internet connection.

On this page

  • Getting started
  • Working faster
  • Getting the result you need
  • Automation and privacy
  • Reference

This guide covers every feature. Start with Install and update, then Convert files, and dip into the rest when you need it.

Getting started

  • Install and update: GitHub download or Microsoft Store, and how updates work
  • Convert files: the main window, formats, quality and where files are saved

Working faster

  • Quick Convert wheel: convert without opening the app, from File Explorer, the desktop, Open and Save dialogs, or the clipboard
  • Right-click menu: S Converter in File Explorer's menu
  • Presets and recipes: one-click presets, your own presets, and recipes that do several steps at once
  • Keyboard shortcuts: every key, in one place

Getting the result you need

  • Make it fit: a maximum file size (under 100 KB, under 20 MB) and photos for visa, passport and exam forms
  • Trim, watermark and rename: edit before you convert
  • PDF tools: merge, split, compress, rotate, number, extract, lock and unlock
  • Archives: ZIP, 7Z, RAR and TAR.GZ, with passwords

Automation and privacy

  • Watch folders and history: convert new files automatically, and see what you converted
  • Privacy and private copies: what stays on your PC, and removing location from photos
