Trim, watermark and rename

The Edit buttons on the right change files as they're converted. Your originals are never changed.

On this page

  • Trim (video and audio)
  • Watermark (photos and video)
  • Rename

Trim (video and audio)

  1. Add a video or audio file and press Trim.
  2. Drag the start and end handles on the timeline, or type the times.
  3. Play the selection to check it, then press Apply segment.

Remove trim goes back to the full length.

Watermark (photos and video)

  1. Press Watermark. The designer opens over one of your files.
  2. Choose Text (your name, the date, the file name) or Logo (a PNG, SVG, JPG or WebP; a transparent PNG looks best).
  3. Set the font, size, colour and opacity; add a background box for legibility.
  4. Drag it into place on the preview, or pick a position. Arrow keys nudge it.
  5. Repeat in 5 places makes it harder to crop out; on video it can also scroll across.
  6. Press Apply watermark. The same design goes on every file in the batch.

Rename

  1. Press Rename.
  2. Type a pattern, for example Holiday-{n}. The preview shows the new names.
  3. Press Use these names, then Convert.
PieceBecomes
{n}the file's number: 001, 002, 003
{date}when the photo was taken (from the camera), otherwise the file's date: 2026-08-14
{name}the original name

{date} Beach {n} gives 2026-08-14 Beach 001. Characters Windows doesn't allow are left out. Keep original names turns renaming off.
