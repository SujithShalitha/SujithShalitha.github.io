Pack folders and files

Select folders (or files) in File Explorer, press Ctrl + Alt + C, and pick:

ChoiceWhat you get
ZIPopens everywhere, built into Windows and macOS
7Zbest compression; opens with 7-Zip or WinRAR
RARneeds WinRAR installed
TAR.GZthe usual archive on Linux and macOS
Fast ZIPno compression, instant, for photos and videos
Smallest ZIP / Ultra 7Zmaximum compression, takes longer
Locked ZIPpassword-protected with AES-256

With several items selected, the wheel asks: one archive or separate ones.

Extract

Select an archive and choose Extract (next to the archive, without a pointless extra folder) or Folder (into a new folder named after the archive). S Converter opens ZIP, 7Z, RAR, TAR, GZ, BZ2, XZ, ISO and CAB, and asks for the password when an archive has one.

Convert archives

An archive can become a ZIP that opens anywhere, or a smaller 7Z.

Names in other languages

ZIP files with names in Sinhala, Chinese, emoji and other scripts pack and unpack correctly. For 7Z, TAR.GZ and locked ZIP files with such names, install 7-Zip; S Converter uses it automatically.
