Settings, languages and themes

Press Settings at the bottom of the sidebar. Changes apply straight away.

SettingWhat it does
Language (top)20 languages; Automatic (Windows) follows your Windows language
Default Output Folderwhere files go when Save at source folder is off
Default Qualitywhere the Quality slider starts
Hardware accelerationGPU (auto) uses your NVIDIA, Intel or AMD graphics card for video and falls back to the processor if needed; CPU only never uses it
Quick Convert shortcutthe wheel's key, for example Ctrl + Alt + C or F8, or off
More shortcutskeys for the wheel's Presets page and Repeat last
UpdatesCheck now; updates otherwise install by themselves
Explorer right-click menuadds S Converter to File Explorer's menu
Watch foldersconvert new files automatically
ThemeLumen, Aether, Silver or Gel

Languages

English, Sinhala (සිංහල), German, Spanish, French, Italian, Dutch, Polish, Portuguese (Brazil), Turkish, Indonesian, Vietnamese, Russian, Ukrainian, Hindi, Thai, Chinese (Simplified and Traditional), Japanese and Korean. The app, the wheel, the tray menu and notifications all switch.

Themes

  • Lumen (default): floating glass over a soft sunrise.
  • Aether: deep purple.
  • Silver: classic chrome with a blue display.
  • Gel: pinstripes and glossy gel, like classic Mac OS X.

The Quick Convert wheel follows the theme you pick.
