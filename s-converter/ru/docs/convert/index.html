Конвертация файлов

Главное окно состоит из трёх частей: категории слева, ваши файлы в центре и Параметры вывода справа.

Конвертация в четыре шага

  1. Выберите категорию слева: Изображения, Аудио, Видео, Документы, Инструменты PDF или Сжать.
  2. Перетащите файлы или целые папки в окно или нажмите Выбрать файлы. Файлы другого типа автоматически попадают в свою категорию.
  3. Справа выберите Формат (например JPG, MP4 или PDF) и настройте параметры.
  4. Нажмите Преобразовать. Кнопка показывает, сколько файлов будет обработано.

По окончании экран Преобразование завершено показывает каждый новый файл, сколько места сэкономлено, и кнопки, чтобы открыть их или показать в папке.

Куда попадают готовые файлы

По умолчанию новые файлы сохраняются рядом с оригиналами с добавкой SC к имени, например Holiday.heic → HolidaySC.jpg. Ничего никогда не перезаписывается. Отключите Сохранять в исходную папку, чтобы сохранять всё в одну папку, и нажмите Изменить, чтобы её выбрать.

Шаблоны в один клик

Когда файлы добавлены, над списком появляется строка Один клик: Почта, Instagram, Веб, Сжать, Миниатюра, Приватная копия, До 100 КБ, Фото для анкеты для изображений и похожие шаблоны для видео, аудио и документов. Шаблон сразу конвертирует с настройками для этой задачи. См. Шаблоны и рецепты.

Предпросмотр

Нажмите Предпросмотр, чтобы посмотреть файл перед конвертацией. Для водяных знаков предпросмотр показывает знак ровно там, где он будет.

Пауза и отмена

Во время конвертации можно поставить Паузу (текущий файл сначала завершится) или Отменить. При отмене недоделанный файл удаляется, а уже готовые сохраняются.

Советы

  • Перетащите папку, чтобы добавить все поддерживаемые файлы из неё.
  • Фото HEIC с iPhone и RAW с фотокамер конвертируются в JPG, PNG, WebP и другие форматы.
  • Для видео S Converter автоматически использует вашу видеокарту NVIDIA, Intel или AMD, что обычно в разы быстрее.
