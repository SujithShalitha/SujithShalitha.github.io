Переименовать пакет файлов при конвертации

Фото с телефона получают имена вроде IMG_20260814_174512. S Converter может дать новым файлам аккуратные имена при конвертации, например Отпуск-001, Отпуск-002 и так далее.

Переименование при конвертации

  1. Перетащите файлы в S Converter и выберите формат.
  2. Справа в разделе Правка нажмите Переименовать.
  3. Введите шаблон, например Отпуск-{n}. В предпросмотре видны новые имена.
  4. Нажмите Использовать эти имена, затем Преобразовать.

Элементы шаблона

{n} — номер файла: 001, 002, 003. {date} — дата съёмки (по данным камеры) или дата файла в виде 2026-08-14. {name} — исходное имя. Сочетайте их со своими словами: {date} Пляж {n} даёт 2026-08-14 Пляж 001. Кнопки + Имя, + Номер и + Дата добавят их за вас.

Полезно знать

Оригиналы сохраняют имена

Шаблон получают только новые, конвертированные файлы.

Правильная сортировка

Номера дополняются нулями (001, 002), поэтому файлы везде идут по порядку.

Настоящие даты съёмки

{date} берёт время съёмки, а не время копирования.

Вопросы

Как вернуть обычные имена?

Откройте «Переименовать» и нажмите «Сохранить исходные имена».

Символы, которые Windows не разрешает?

Они автоматически пропускаются в новых именах.
