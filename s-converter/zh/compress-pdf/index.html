在 Windows 上离线压缩 PDF

太大没法发邮件或上传？S Converter 在你的电脑上缩小 PDF，不必把文档发到网站上。

用 S Converter 怎么做

  1. 打开 S Converter，在侧边栏选择 PDF 工具。
  2. 选择压缩.
  3. 把 PDF 拖进来。
  4. 点击转换。缩小后的副本会保存在原文件旁边，S Converter 还会显示节省了多少空间。

或直接从文件资源管理器操作

  1. 在文件资源管理器中选中 PDF。
  2. 按 Ctrl + Alt + C，在转盘上点击压缩。

只要 S Converter 在运行（它会在系统托盘中待命），快捷键就有效。GitHub 版本还可以右键点击文件并选择 S Converter；在 Windows 11 中位于显示更多选项里.

常见问题

能缩小多少？

满是照片或扫描页的 PDF 往往能缩小很多；以文字为主的 PDF 本来就小，变化较少。

处理机密文件安全吗？

安全。一切都在你的电脑上完成，不会上传任何内容。
