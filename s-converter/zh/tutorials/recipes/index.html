配方：一键完成转换、重命名和打包

配方是能做不止一件事的预设。调整照片尺寸、重命名为 旅行-001、002…，再全部放进一个 PDF：设置一次，以后每次一键完成。

创建配方

  1. 打开图片（或其他分类），添加几个文件。
  2. 在右侧设置格式和选项。如需同时重命名，点击重命名并输入命名规则，例如 旅行-{n}.
  3. 在一键栏末尾点击＋ 保存并输入名称。
  4. 如果设置了重命名规则，请保持勾选同时重命名文件。在完成后下选择全部放进一个 ZIP或全部放进一个 PDF.
  5. 点击保存。你的配方会出现在一键栏中。

使用预设

添加文件后点击该配方，或在快速转换转盘的预设页上选择它。S Converter 会完成转换、重命名和打包，最后只保留最终的 ZIP 或 PDF。

创意示例

旅行相册：1600 像素 JPG → 旅行-{n} → 一个 PDF。发给客户：水印 → 一个 ZIP。扫描件：文档 → PDF → 一个 ZIP 用于归档。

常见问题

哪些配方可以生成 PDF？

输出 JPG、PNG、WebP 或 TIFF 图片的配方，以及照片的压缩配方。

监视文件夹能运行配方吗？

监视文件夹运行的是格式和预设；会打包文件的配方最好手动运行。
