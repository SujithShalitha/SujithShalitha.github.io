一步步学会 S Converter

每个功能都有简短教程，包含确切步骤和常见问题解答。刚开始用 S Converter？从入门开始.

S Converter 入门

S Converter 在你自己的电脑上转换图片、视频、音频、文档和 PDF。

→

快速转换：不打开应用也能转换文件

在 Windows 上最快的转换方式：在文件原来的位置选中它们，按快捷键，点击格式。

→

从右键菜单转换文件

如果你更习惯用鼠标，S Converter 会把自己添加到文件资源管理器的右键菜单中。

→

一键预设：邮件、Instagram、WhatsApp 等

大多数时候你要的不是“某种格式”，而是“小到能发邮件”或“正好适合 Instagram”。

→

把视频压到适合 WhatsApp 或邮件的大小

手机视频体积很大，而 WhatsApp、邮件和上传表单都有大小限制。

→

为照片和视频添加水印

分享前先保护好你的照片和视频。

→

剪辑视频或音频文件

只保留精彩部分。

→

给文件夹打包加密 ZIP，并解压压缩包

Windows 能把文件夹打包成 ZIP，但不能加密码。

→

拆分、旋转、加页码和提取 PDF 页面

S Converter 的 PDF 工具无需 Acrobat，也不用把文档上传到任何地方，就能完成日常 PDF 任务。

→

设置：主题、GPU 速度、输出文件夹和更新

S Converter 开箱即用，但调整几个设置能让它更快、更合你心意。

→

保存自己的预设

如果你总是选择相同的格式、质量和尺寸，就把它们保存成自己的预设。

→

去除照片和视频中的位置和相机信息

手机拍的照片通常带有隐藏信息：拍摄地点、相机型号以及日期时间。

→

转换时批量重命名文件

手机照片的文件名通常像 IMG_20260814_174512 这样。

→

给 PDF 加密码，或解除密码

要发送合同、工资单或病历？先给 PDF 加上密码。

→

监视文件夹：自动转换新文件

有些任务每天都要重复：屏幕截图转 JPG、扫描件转 PDF、手机照片去掉位置信息。

→

用你的语言使用 S Converter

S Converter 提供 20 种语言，并会自动使用你的 Windows 语言。

→

让文件符合大小限制

上传表单、邮件和聊天应用都有大小限制。

→

配方：一键完成转换、重命名和打包

配方是能做不止一件事的预设。

→

粘贴为…：转换剪贴板中的图片

复制了图片或截了图？不选中任何文件时按快速转换快捷键：转盘会为剪贴板中的图片打开，转换后的图片会回到剪贴板。

→

在找特定的转换方法？

  • 在 Windows 上将 HEIC 转换为 JPG
  • 在 Windows 上将 WebP 转换为 JPG 或 PNG
  • 在 Windows 上将 JPG 等图片转换为 PDF
  • 在 Windows 上将 PDF 页面转换为 JPG 图片
  • 无需 Microsoft Office 将 Word 转换为 PDF
  • 无需 Office 将 PowerPoint 转换为 PDF
  • 在 Windows 上离线压缩 PDF
  • 在 Windows 上合并 PDF 文件
  • 在 Windows 上将 MKV 转换为 MP4
  • 在 Windows 上从视频中提取 MP3 音频
  • 在 Windows 上把视频做成 GIF
  • 在 Windows 上批量调整和压缩照片
  • 在 Windows 上把照片压缩到 100 KB 以内
  • 制作美国签证照片：600 × 600 像素，240 KB 以内
  • 为护照或身份证件调整照片尺寸（35 × 45 mm）
  • 把视频压缩到 20 MB 以内用于邮件
  • 直接从剪贴板将截图或复制的图片转换为 JPG
  • 为 Discord 压缩视频（10 MB 以内）
