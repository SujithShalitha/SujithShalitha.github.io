设置、语言和主题

点击侧边栏底部的设置。更改立即生效。

设置作用
语言（顶部）20 种语言；自动（Windows）跟随你的 Windows 语言
默认输出文件夹关闭保存到源文件夹时文件的保存位置
默认质量质量滑块的初始位置
硬件加速GPU（自动）使用 NVIDIA、Intel 或 AMD 显卡处理视频，必要时回退到处理器；仅 CPU从不使用显卡
快速转换快捷键转盘的按键，例如 Ctrl + Alt + C 或 F8，也可关闭
更多快捷键转盘预设页和重复上次的按键
更新立即检查；否则更新会自动安装
资源管理器右键菜单把 S Converter 添加到文件资源管理器的菜单中
监视文件夹自动转换新文件
主题Lumen、Aether、Silver 或 Gel

语言

英语、僧伽罗语（සිංහල）、德语、西班牙语、法语、意大利语、荷兰语、波兰语、葡萄牙语（巴西）、土耳其语、印度尼西亚语、越南语、俄语、乌克兰语、印地语、泰语、中文（简体和繁体）、日语和韩语。应用、转盘、托盘菜单和通知都会切换。

主题

  • Lumen（默认）：柔和日出上方悬浮的玻璃质感。
  • Aether：深紫色。
  • Silver：经典金属质感配蓝色显示屏。
  • Gel：细条纹和光泽凝胶，就像经典的 Mac OS X。

快速转换转盘会跟随你选择的主题。
