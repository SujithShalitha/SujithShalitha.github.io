安装和更新

S Converter 可在 Windows 10（1809 或更新版本）和 Windows 11（64 位）上运行。无需管理员权限，也不需要 Microsoft Office 或其他软件。

本页内容

  • 两种安装方式
  • “Windows 已保护你的电脑”
  • 更新
  • 卸载

两种安装方式

Microsoft Store从 GitHub 下载
位置apps.microsoft.comgithub.com/SujithShalitha/s-converter-releases
大小安装包约 240 MB安装程序约 170 MB
首次运行时的警告无“Windows 已保护你的电脑”（见下文）
更新由 Microsoft Store 负责由 S Converter 自己在后台完成

两者是同一个应用，功能完全相同。选一个就好，不需要都装。

“Windows 已保护你的电脑”

GitHub 安装程序没有使用付费代码签名证书，因此 Windows SmartScreen 第一次会显示警告。点击更多信息，再点击仍要运行。只需操作一次：之后更新会自动安装。Microsoft Store 版本从不显示此警告。

更新

  • GitHub 版本：S Converter 会在后台检查更新、下载并在你没有转换文件时安装。你也可以打开设置 → 更新 → 立即检查.
  • Store 版本：由 Microsoft Store 保持最新。

关于（侧边栏底部）会显示你的版本、显卡以及哪些内置工具已就绪。

卸载

在 Windows 中打开设置 → 应用 → 已安装的应用 → S Converter → 卸载。右键菜单项也会一并移除。你转换好的文件不会被动。
