PDF 工具

在左侧打开 PDF 工具，在顶部选择一个工具。

本页内容

  • 加密 PDF
  • 解密 PDF
  • 在转盘上
工具作用保存为
图片 → PDF把 JPG、PNG、WebP、BMP 或 TIFF 合成一个 PDF，或每张图片一个 PDFname.pdf
PDF → 图片每页生成一张清晰的 JPGnameSC_page1.jpg, nameSC_page2.jpg …
合并将多个 PDF 从上到下合成一个；用 ▲ ▼ 调整顺序name_merged.pdf
拆分按 1-3, 4-9 这样的页面范围拆分，或每页一个 PDF每个范围一个 PDF
压缩缩小其中的图片；文字保持清晰name_compressed.pdf
旋转每页旋转 90 度，可选方向name_rotated.pdf
页码在底部添加“第 1 页，共 9 页”之类的页码name_numbered.pdf
提取页面只保留你列出的页面，并按该顺序排列（9- 表示第 9 页到最后）name_pages.pdf
加密添加密码，AES-256name_locked.pdf
解密移除你知道的密码及编辑限制name_unlocked.pdf

加密 PDF

选择加密，添加 PDF，输入两次密码，点击加密。没有密码谁都打不开加密后的副本，所以请妥善保管密码。

解密 PDF

选择解密，添加 PDF，如有密码就输入，点击解密。生成的副本没有密码，也没有打印或复制限制。

解密只能移除你知道的密码。没有密码，谁也打不开 AES-256 加密的 PDF。

在转盘上

在文件资源管理器中选中 PDF，按 Ctrl + Alt + C 可使用压缩、合并（按文件名顺序）、JPG、加密和解密。从转盘把图片合成一个 PDF 时，页面顺序界面可以先调整页面顺序。
