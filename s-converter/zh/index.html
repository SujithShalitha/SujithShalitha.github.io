功能

在线转换器能做的，这里都能做，而且不用上传

批量转换一切

拖入一个文件或整个文件夹，选择格式，点击转换。邮件、Instagram、网页和缩略图等一键预设帮你搞定日常任务，节省了多少空间也一目了然。

  • iPhone HEIC 转 JPG、WebP 转 PNG、相机 RAW 等
  • 一次为所有文件调整尺寸、压缩和更改质量
  • 保存你自己的一键预设，或者能转换、重命名并打包成一个 ZIP 或 PDF 的配方
  • 转换时批量重命名：假期-001、002…
  • 永不覆盖原文件

压到限制以内：文件大小限制和证件照

上传表单要求100 KB 以内，邮件上限 20 MB。把质量切换为最大大小，选择限制，S Converter 会找到符合限制的最佳质量。证件照会把照片裁剪成签证、护照或考试报名表要求的精确尺寸。

  • 100 KB 以内的照片，或 200 KB、1 MB 及你输入的任意限制
  • 美国签证照片：600 × 600 像素，240 KB 以内；护照 35 × 45 mm、2 × 2 英寸，或你自己的尺寸
  • 20 MB 以内的邮件视频、16 MB 的 WhatsApp 视频，或任意大小
  • 你的证件照绝不会离开你的电脑

快速转换，直接在文件资源管理器中完成

在文件资源管理器、桌面或任意打开/保存对话框中选中文件，按 Ctrl + Alt + C，或右键选择 Quick Convert。转盘会在鼠标旁边打开：指向一个格式并点击。连应用都不用打开。

  • WhatsApp、制作 GIF、提取音频和加密 ZIP等预设
  • 多张照片合成一个 PDF，页面顺序可调整，或每张照片一个 PDF
  • 粘贴为…：什么都没选中？它会转换剪贴板中的图片，再把结果复制回去
  • 记住你的常用格式：用得最多的格式会排到前面
  • 也能处理文件夹：打包成 ZIP、7Z 或 RAR
  • 自定义按键，例如 F8，还可为预设和重复上次设置快捷键

视频处理，用上你的显卡

在 MP4、MKV、MOV、WebM、AVI 等格式之间转换，制作 GIF、提取音频、更改分辨率，并在可视化时间轴上剪辑片段。S Converter 会检测 NVIDIA、Intel 和 AMD 显卡，并自动使用它们大幅加快编码。

处理文档，无需 Office

Word、PowerPoint、Excel、OpenDocument、RTF、Markdown、HTML 和 EPUB，都由 S Converter 自带的引擎转换。无需 Microsoft Office 或 LibreOffice。

  • Word 转 PDF 保留标题、列表、表格、图片和链接
  • PowerPoint 转 PDF 保留每张幻灯片的版式和颜色
  • 文档中的表格可以转成 Excel 电子表格

PDF 工具，私密处理

平时要去 PDF 网站才能做的事，在你自己的电脑上就能完成。甚至可以给 PDF 加密码:

照片和视频水印

添加你的名字或徽标，在实时预览中拖到合适位置，设置大小、颜色和不透明度，重复排列让它更难被裁掉，或让它在视频上滚动。一个设计，应用到整批文件。

压缩包与密码

  • 将文件夹打包为 ZIP、7Z、RAR 或 TAR.GZ
  • 用密码保护：ZIP 使用 AES-256 加密
  • 解压 ZIP、7Z、RAR、TAR、ISO 和 CAB，包括有密码的压缩包

隐私副本，去掉隐藏信息

手机照片会记录拍摄地点、相机和时间。点一下隐私副本，就能保存一份去掉这些信息的副本，可以放心分享。画质不变，视频不会重新编码。

  • 移除 GPS 位置、相机信息和日期
  • 照片和视频，批量处理
  • 与 EXIF 清除网站不同，不上传任何内容

常见问题

常见问题解答

S Converter 真的免费吗？

是的。没有广告、没有试用期、无需账号、没有限制，也不会在你的文件上加水印。

我的文件会被上传到什么地方吗？

不会。每次转换都在你自己的电脑上进行，S Converter 没有网络也能用。它唯一会下载的是它自己的更新。查看隐私政策.

不装 Microsoft Office 能把 Word 或 PowerPoint 转成 PDF 吗？

能。S Converter 有自己的文档引擎，DOCX、DOC、ODT、RTF、PPTX、XLSX、EPUB、Markdown 和 HTML 都能转成 PDF，无需安装其他软件。

能把 iPhone 的 HEIC 照片转成 JPG 吗？

能，而且支持批量。HEIC/HEIF 和相机 RAW 文件可转换为 JPG、PNG、WebP、AVIF、TIFF 或 PDF。

为什么 Windows 会提示“Windows 已保护你的电脑”？

对于没有使用付费代码签名证书的新程序，Windows 都会显示这个提示。点击更多信息 → 仍要运行即可。只需操作一次：之后更新会自动安装。如果想避免这个提示，可以从 Microsoft Store 获取 S Converter。

能去除照片中的位置信息吗？

能。隐私副本会保存一份去掉 GPS 位置、相机信息和日期的照片或视频副本，画质不变。查看如何去除照片中的位置信息.

能把照片压缩到 100 KB 以内吗？

能。把质量切换为最大大小，选择 100 KB 或任意限制；S Converter 会找到符合限制的最佳质量。证件照可以制作尺寸精确的签证、护照和考试照片。查看把图片压缩到 100 KB和制作美国签证照片.

有使用手册吗？

有：S Converter 文档一步步讲解每个功能。它也发布在 GitHub 上.

能给 PDF 加密码吗？

能。在 PDF 工具中，加密会用 AES-256 加密添加密码，解密可移除你知道的密码。查看如何给 PDF 加密.

支持哪些语言？

20 种：英语、僧伽罗语、德语、西班牙语、法语、意大利语、荷兰语、波兰语、葡萄牙语（巴西）、土耳其语、印度尼西亚语、越南语、俄语、乌克兰语、印地语、泰语、中文（简体和繁体）、日语和韩语。它会自动跟随你的 Windows 语言；查看如何更改.

转换后的文件保存在哪里？

默认保存在原文件旁边，文件名加上“SC”，所以永远不会覆盖任何文件。你也可以选择其他文件夹。

快速转换快捷键不起作用。

可能有其他程序已经占用了 Ctrl + Alt + C。在设置 → 快速转换快捷键中换一个。S Converter 会留在系统托盘中，所以关闭窗口后快捷键仍然有效。

如何卸载？

Windows 设置 → 应用 → 已安装的应用 → S Converter → 卸载。右键菜单项也会一并移除。
