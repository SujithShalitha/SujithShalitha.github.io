Verrouiller un PDF

Choisissez Verrouiller, ajoutez les PDF, tapez un mot de passe deux fois, appuyez sur Verrouiller. Personne ne peut ouvrir la copie verrouillée sans le mot de passe, alors conservez-le précieusement.

Déverrouiller un PDF

Choisissez Déverrouiller, ajoutez le PDF, tapez son mot de passe s’il en a un, appuyez sur Déverrouiller. La copie n’a ni mot de passe ni restriction d’impression ou de copie.

Déverrouiller retire un mot de passe que vous connaissez. Personne ne peut ouvrir un PDF AES-256 sans son mot de passe.

Depuis la roue

Sélectionnez des PDF dans l’Explorateur de fichiers et appuyez sur Ctrl + Alt + C pour Compresser, Fusionner (dans l’ordre des noms), JPG, Verrouiller et Déverrouiller. Pour images → un PDF depuis la roue, l’écran Ordre des pages vous permet d’abord d’organiser les pages.
