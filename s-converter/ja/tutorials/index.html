チュートリアル

S Converter をステップごとに学ぶ

各機能の短いチュートリアル。正確な手順とよくある質問への回答付き。S Converter が初めてなら、はじめにから始めましょう.

S Converter を使い始める

S Converter は画像、動画、音声、文書、PDF をお使いの PC で変換します。

→

クイック変換：アプリを開かずにファイルを変換

Windows で最速の変換方法：ファイルがある場所でそのまま選び、ショートカットを押して形式をクリック。

→

右クリックメニューからファイルを変換

マウス派の方のために、S Converter はエクスプローラーの右クリックメニューに追加されます。

→

ワンクリックプリセット：メール、Instagram、WhatsApp など

たいていの場合、欲しいのは「ある形式」ではなく「メールで送れる小ささ」や「Instagram にぴったり」です。

→

WhatsApp やメールで送れるよう動画を小さくする

スマホの動画は大きく、WhatsApp、メール、アップロードフォームにはそれぞれ上限があります。

→

写真や動画に透かしを入れる

共有する前に写真や動画を守りましょう。

→

動画や音声ファイルをトリムする

いいところだけを残しましょう。

→

フォルダーをパスワード付き ZIP にし、アーカイブを展開する

Windows はフォルダーを ZIP にできますが、パスワードは付けられません。

→

PDF のページを分割、回転、番号付け、取り出す

S Converter の PDF ツールなら、Acrobat なしで、文書をどこにもアップロードせずに日常の PDF 作業ができます。

→

設定：テーマ、GPU による高速化、出力フォルダー、更新

S Converter はそのままでも快適に使えますが、いくつかの設定でさらに速く、自分好みにできます。

→

自分のプリセットを保存する

いつも同じ形式、品質、サイズを選んでいるなら、一度プリセットとして保存しましょう。

→

写真や動画から位置情報やカメラ情報を削除する

スマートフォンの写真には通常、撮影場所、カメラ、日時といった隠れた情報が含まれています。

→

変換しながらファイルをまとめて名前変更

スマホの写真には IMG_20260814_174512 のような名前が付いています。

→

PDF にパスワードを付ける、または解除する

契約書や給与明細、診断書を送りますか？先に PDF にパスワードを付けましょう。

→

監視フォルダー：新しいファイルを自動で変換

スクリーンショットを JPG に、スキャンを PDF に、スマホ写真を位置情報なしに。毎日くり返す作業があります。

→

S Converter をあなたの言語で使う

S Converter は 20 言語に対応し、Windows の言語で自動的に起動します。

→

ファイルをサイズ上限に収める

アップロードフォーム、メール、チャットアプリにはそれぞれ上限があります。

→

レシピ：変換、名前の変更、まとめをワンクリックで

レシピは、複数のことを行うプリセットです。

→

貼り付け形式…：クリップボードの画像を変換

画像をコピーしたりスクリーンショットを撮ったりしましたか？何も選択せずにクイック変換のショートカットを押すと、クリップボードの画像用にホイールが開き、変換した画像がクリップボードに戻ります。

→

特定の変換方法をお探しですか？

  • Windows で HEIC を JPG に変換
  • Windows で WebP を JPG や PNG に変換
  • Windows で JPG などの画像を PDF に変換
  • Windows で PDF のページを JPG 画像に変換
  • Microsoft Office なしで Word を PDF に変換
  • Office なしで PowerPoint を PDF に変換
  • Windows で PDF をオフライン圧縮
  • Windows で PDF ファイルを結合
  • Windows で MKV を MP4 に変換
  • Windows で動画から MP3 音声を取り出す
  • Windows で動画から GIF を作る
  • Windows で写真をまとめてリサイズ・圧縮
  • Windows で写真を 100 KB 以下に圧縮
  • 米国ビザ用写真を作る：600 × 600 ピクセル、240 KB 以下
  • パスポートや身分証用に写真のサイズを変更（35 × 45 mm）
  • メール用に動画を 20 MB 以下に圧縮
  • スクリーンショットやコピーした画像をクリップボードから直接 JPG に変換
  • Discord 用に動画を圧縮（10 MB 以下）
