Ein PDF mit Passwort sperren oder entsperren

Du verschickst einen Vertrag, eine Gehaltsabrechnung oder einen Arztbrief? Sperre das PDF vorher mit einem Passwort. Und wenn du ein passwortgeschütztes PDF nicht mehr ständig entsperren willst, kann S Converter eine Kopie ohne Passwort speichern.

Ein PDF sperren

  1. Öffne PDF-Tools und wähle Sperren.
  2. Zieh ein oder mehrere PDFs hinein.
  3. Gib rechts ein Passwort ein und dann noch einmal.
  4. Klicke auf Sperren. Die gesperrte Kopie wird als name_locked.pdf gespeichert.

Ein PDF entsperren

  1. Öffne PDF-Tools und wähle Entsperren.
  2. Zieh das PDF hinein.
  3. Wenn es zum Öffnen ein Passwort verlangt, gib es rechts ein.
  4. Klicke auf Entsperren. Die Kopie, name_unlocked.pdf, hat kein Passwort und keine Sperren beim Drucken oder Kopieren.

Gut zu wissen

AES-256

Dieselbe starke Verschlüsselung, die Banken nutzen. Ohne das Passwort kann niemand die Datei öffnen.

Privat

Deine Dokumente werden nie auf eine PDF-Website hochgeladen.

Originale unangetastet

Sperren und Entsperren erstellen immer eine neue Kopie.

Fragen

Ich habe das Passwort meines PDFs vergessen. Kann es das entsperren?

Nein. Entsperren entfernt ein Passwort, das du kennst. Niemand kann ein AES-256-PDF ohne sein Passwort öffnen, und genau das macht das Sperren sicher.

Braucht der Empfänger spezielle Software?

Nein. Jeder PDF-Reader fragt nach dem Passwort: Edge, Chrome, Adobe Reader, auch Handys.

Kann ich mehrere PDFs auf einmal sperren?

Ja. Zieh sie alle hinein; jede bekommt ihre eigene gesperrte Kopie mit demselben Passwort.
