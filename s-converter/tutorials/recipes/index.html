Recipes: convert, rename and pack in one click

A recipe is a preset that does more than one thing. Resize photos, rename them Trip-001, 002… and put them all into one PDF: set it up once, then it’s one click every time.

Make a recipe

  1. Open Images (or another category) and add a few files.
  2. Set the format and options on the right. To rename too, press Rename and type a pattern such as Trip-{n}.
  3. Press ＋ Save at the end of the One-click row and type a name.
  4. If you set a rename pattern, leave Also rename the files ticked. Under When it’s done choose Put them all in one ZIP or Put them all in one PDF.
  5. Press Save. Your recipe appears in the One-click row.

Use it

Add files and press the recipe, or choose it on the Presets page of the Quick Convert wheel. S Converter converts, renames and packs everything, then keeps only the final ZIP or PDF.

Ideas

Trip album: 1600 px JPG → Trip-{n} → one PDF. Send to client: watermark → one ZIP. Scans: documents → PDF → one ZIP for archiving.

Good to know

Fewer clicks

Three jobs become one.

Tidy results

The in-between files are removed; only the ZIP or PDF stays.

Everywhere

Recipes work from the app and the wheel.

Questions

Which recipes can make a PDF?

Recipes that make JPG, PNG, WebP or TIFF images, and Compress recipes for photos.

Can a watch folder run a recipe?

Watch folders run formats and presets; recipes that pack files are best run by hand.
