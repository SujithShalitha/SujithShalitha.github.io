Merge PDF files on Windows

Join statements, forms or chapters into one PDF without an online tool.

Download S Converter

How to do it with S Converter

  1. Open S Converter and choose PDF Tools in the sidebar.
  2. Pick Merge.
  3. Drag in the PDFs, then use the ▲ and ▼ buttons in the list to put them in order.
  4. Press Convert. You get one PDF with all the pages.

Or right from File Explorer

  1. Select the PDFs in File Explorer.
  2. Press Ctrl + Alt + C and click Merge on the wheel.

The shortcut works while S Converter is running (it waits in the system tray). In the version from GitHub you can also right-click files and choose S Converter; on Windows 11 it's under Show more options.

Questions

Can I split a PDF too?

Yes. PDF Tools → Split saves every page separately, or by ranges like 1-3, 4-8, 9-.

Can I add page numbers to the merged PDF?

Yes. Run PDF Tools → Page numbers on the merged file.
